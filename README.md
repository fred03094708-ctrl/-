# 할 일 관리

브라우저에서 `index.html`을 열면 바로 사용할 수 있는 할 일 관리 앱입니다.

- 할 일 추가 / 완료 체크 / 삭제
- 더블클릭으로 제목 수정
- 마감일(지난 항목 강조), 우선순위(높음·보통·낮음)
- 전체 / 진행 중 / 완료 필터, 완료 항목 일괄 삭제
- 데이터는 브라우저(localStorage)에 저장

## PB 업무 데스크 (`app/pb-desk.html`)

증권 PB 업무용으로 확장한 버전입니다. claude.ai 아티팩트로 게시해서 사용합니다.

- 오늘 화면: 지연·오늘·7일 내 만기·연락할 고객 요약
- 할 일: 고객 연결, 분류(고객상담·리밸런싱·만기·상품제안·컴플라이언스 등), 반복 일정, 검색, PB 업무 템플릿
- 고객: 등급(VVIP/VIP/일반), 연락 주기, 연락 지연 알림, "연락함" 한 번에 기록
- 기기 간 동기화(본인 계정 전용 저장소), Google 캘린더 등록, 데스크톱 앱 설치
